# 贪吃蛇 · Snake

一个精致的网页版贪吃蛇，纯 HTML / CSS / JavaScript 实现，无任何依赖，双击 `index.html` 即可游玩，桌面与手机通用。

## 两位玩家

开始菜单里先选「谁来玩」：**景**（默认星际主题）和 **娜**（默认甜心主题）。

- 各记各的分，按「模式 × 难度」分别保存；领先的人头上戴 👑
- 主题跟着人走：点谁的头像，整个界面就换成谁的主题；按 `T` 换的是当前玩家自己的主题
- 结算时先和对方比：「距离娜的纪录还差 30 分」「超过景的纪录 20 分」
- 玩家名字和默认主题在 `src/scripts/app.js` 顶部的 `PLAYERS` 里修改

## 三套主题

每位玩家按 `T` 循环切换，选择会被记住：

| 主题 | 风格 | 蛇 | 食物 / 奖励 | 障碍 |
| --- | --- | --- | --- | --- |
| 霓虹 | 黑底网格，青紫品红的霓虹灯管 | 青 → 品红渐变灯管 | 品红光球 / 金色星星 | 紫色灯框 |
| 星际 | 太空歌剧，星空与流星 | 战机拖着光束（轻松绿、标准蓝、困难红） | 光环行星 / 能量晶体 | 金属装甲板 |
| 甜心 | 粉嫩可爱，圆点与爱心 | 糖果色圆珠，戴蝴蝶结的笑脸 | 草莓 / 会笑的星星糖 | 软绵绵的云朵 |

每套主题都有独立的配色、文案、粒子效果和音效。

## 特性

- **菜单演示**：开始菜单背后有一条自动游走的蛇，预览当前模式与难度的速度
- **流畅手感**：Canvas 渲染 + 帧间插值，蛇身平滑移动；方向输入缓冲，快速连按不丢键
- **三种难度**：轻松 / 标准 / 困难，起始速度与得分倍率不同，吃得越多速度越快
- **三种模式**
  - 经典：撞墙或撞到自己即结束
  - 穿墙：从边界穿出、另一侧进入
  - 障碍：四角障碍布局，每升一级随机新增岩石
- **等级系统**：每吃 5 个食物升一级，单个食物分值随等级提高
- **金色奖励**：随机出现、限时 6 秒的星星，+50 × 难度倍率
- **最高分记录**：按「玩家 × 模式 × 难度」分别保存在本地，刷新不丢失
- **视听反馈**：粒子爆裂、得分飘字、死亡震屏、WebAudio 合成音效（可静音）
- **公平手感**：即将撞墙/撞到自己时停顿一拍，仍可转向逃生；吃到食物的特效与蛇头真正接触同步
- **倒计时**：开局与继续游戏前 3-2-1 倒计时，不会一恢复就撞死
- **自动暂停**：切换标签页或最小化时自动暂停
- **移动端适配**：滑动操作 + 虚拟方向键，高清屏清晰渲染

## 操作

| 按键 | 功能 |
| --- | --- |
| `↑ ↓ ← →` / `W A S D` | 移动 |
| `空格` / `P` / `Esc` | 暂停 / 继续 |
| `Enter` | 开始 / 再来一局 |
| `R` | 重新开始（游戏中需连按两次，防误触；工具栏按钮同理） |
| `M` | 静音开关 |
| `T` | 切换当前玩家的主题 |

手机上在棋盘上滑动，或使用下方方向键。

## 运行

直接在浏览器中打开 `index.html`；或使用本地服务器：

```bash
npm install
npm start
```
