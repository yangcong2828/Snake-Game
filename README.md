# 贪吃蛇 · Snake

一个精致的网页版贪吃蛇，纯 HTML / CSS / JavaScript 实现，无任何依赖，双击 `index.html` 即可游玩，桌面与手机通用。

## 三套主题

随时在工具栏切换（或按 `T`），选择会被记住。也可以在链接后加 `?theme=neon|scifi|sweet` 直接指定主题：

| 主题 | 风格 | 蛇 | 食物 / 奖励 | 障碍 |
| --- | --- | --- | --- | --- |
| 霓虹 | 暗色霓虹，简洁利落 | 发光渐变长蛇 | 苹果 / 金色星星 | 石块 |
| 星际 | 太空歌剧，星空与流星 | 战机拖着光束（轻松绿、标准蓝、困难红） | 光环行星 / 能量晶体 | 金属装甲板 |
| 甜心 | 粉嫩可爱，圆点与爱心 | 糖果色圆珠，戴蝴蝶结的笑脸 | 草莓 / 会笑的星星糖 | 软绵绵的云朵 |

每套主题都有独立的配色、文案、粒子效果和音效。

## 特性

- **流畅手感**：Canvas 渲染 + 帧间插值，蛇身平滑移动；方向输入缓冲，快速连按不丢键
- **三种难度**：轻松 / 标准 / 困难，起始速度与得分倍率不同，吃得越多速度越快
- **三种模式**
  - 经典：撞墙或撞到自己即结束
  - 穿墙：从边界穿出、另一侧进入
  - 障碍：四角障碍布局，每升一级随机新增岩石
- **等级系统**：每吃 5 个食物升一级，单个食物分值随等级提高
- **金色奖励**：随机出现、限时 6 秒的星星，+50 × 难度倍率
- **最高分记录**：按「模式 × 难度」分别保存在本地，刷新不丢失
- **视听反馈**：粒子爆裂、得分飘字、死亡震屏、WebAudio 合成音效（可静音）
- **公平手感**：即将撞墙/撞到自己时停顿一拍，仍可转向逃生；吃到食物的特效与蛇头真正接触同步
- **倒计时**：开局与继续游戏前 3-2-1 倒计时，不会一恢复就撞死
- **自动暂停**：切换标签页或最小化时自动暂停
- **移动端适配**：滑动操作 + 虚拟方向键，高清屏清晰渲染

## 操作

| 按键 | 功能 |
| --- | --- |
| `↑ ↓ ← →` / `W A S D` | 移动 |
| `空格` / `P` / `Esc` | 暂停 / 继续 |
| `Enter` | 开始 / 再来一局 |
| `R` | 重新开始（游戏中需连按两次，防误触） |
| `M` | 静音开关 |
| `T` | 切换主题 |

手机上在棋盘上滑动，或使用下方方向键。

## 运行

直接在浏览器中打开 `index.html`；或使用本地服务器：

```bash
npm install
npm start
```
